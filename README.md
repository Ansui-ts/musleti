# 你是哪一块 · 肌肉人格测验

二十道关于日常的题，测出你是十六块肌肉里的哪一块。原创选题，无 IP 素材。

**在线地址**：https://ansui-ts.github.io/musleti/

## 设计说明

**四维与编码。** 四条轴：怎么使劲 · 谁看得见 · 松还是紧 · 力气给谁。每轴五题，奇数票必出多数，不会平票；四位拼成 `0010` 这样的编码查表。

**极性与配比。** 每题三个选项里有两个同极，是同一倾向的两种表达。五题共 15 席无法对半分，所以让偏斜方向在轴之间对冲：轴 1、轴 2 各多一个「1」，轴 3、轴 4 各多一个「0」。否则某些型会被系统性放大，测出来扎堆。

**图鉴里的四个点。** 就是编码的点阵形式，从左到右依次对应四条轴，填实是 `1`、空心是 `0`。比如斜方肌 `0010`，第三个点亮。

**配套内容。** 「最搭配」用编码反码配对，八对互相印证；「死对头」取解剖上的拮抗关系或功能争抢；「最喜欢的动作」贴着那块肌肉的主司功能。

**数据存哪。** 答题记录与解锁进度只存在浏览器 localStorage（键名 `ms_history` / `ms_unlocked`），不上传任何服务器。换设备、换浏览器、清缓存都会清零，这是静态页面的固有限制。

## 重新生成

`index.html` 是生成物，不要直接改，改动会在下次编译时被覆盖。

```bash
python build.py                       # content.md + questions.md → index.html
cp index.html og.png icon-*.png dist/ # 同步到发布目录
```

`build.py` 会自检，任何一项不过就报错停下：

- 十六型编码不重复，`mate` 反码配对双向自洽
- 每题三个选项，不存在三个同极
- 每型的位置段、性格段、日常段都不为空

**换部署地址**：改 `build.py` 顶部的 `SITE` 常量，重跑一次即可。页面里的 `og:image`、`og:url`、`canonical` 都由它注入，不用手动改 HTML。
